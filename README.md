# Pong
Pong is a classic two-dimensional arcade game that simulates table tennis. The player controls a paddle and competes against either another player or an AI opponent, with the goal of scoring points by getting the ball past the opponent’s paddle.
 The ball moves across the screen and bounces off the top and bottom boundaries as well as the paddles, with its speed gradually increasing to raise the difficulty over time.
This implementation focuses on core game development concepts such as collision detection, real-time input handling, score tracking, and game loop mechanics. It provides a simple yet effective demonstration of interactive gameplay logic and physics-based movement in a 2D environment.
